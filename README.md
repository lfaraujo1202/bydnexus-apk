# BydNexus (APK)

Launcher pessoal para o BYD Song. Este repositório guarda só o instalador, sem o código-fonte.

## Baixar

**Link curto:** **is.gd/bydnexus**

**Versão mais recente:** https://github.com/lfaraujo1202/bydnexus-apk/releases/latest/download/BydNexus.apk

Outras versões ficam em [Releases](https://github.com/lfaraujo1202/bydnexus-apk/releases).

## Instalar na central (carro parado, em P)

1. O Overdrive precisa estar instalado e rodando. O BydNexus lê o carro pela API local dele.
2. Baixe o `BydNexus.apk` pelo link acima e abra-o pelo app **Arquivos**. A central precisa do *PackageInstaller Unlocked* da BYD para instalar APKs de fora da loja.
3. Abra o BydNexus e siga o primeiro uso.

As próximas versões aparecem dentro do app, em **Configurações › Atualizações**, e o app sempre pede confirmação antes de instalar.
